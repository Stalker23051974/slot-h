# SLOT-H

**Single Logical Operating Tool for Hosting**

Мультипроектная PHP-экосистема: один код — десятки сайтов. Одна база данных, одна логика, одна точка входа. Без микросервисов, контейнеризации и Composer.

> Это не фреймворк. Это боевая экосистема, которая родилась из 25 лет боли, 15 лет непрерывного продакшена и сотен проектов, которые нужно было поддерживать.

---

## Что это

SLOT-H позволяет писать код один раз и разворачивать его на множестве проектов одновременно. Ядро само решает, как правильно: маршрутизация, автозагрузка, CSRF-защита, локализация, очереди — уже внутри.

**Философия: соглашение важнее правил.** Ядро знает, как правильно. Ты просто описываешь логику.

---

## Ключевые особенности

- **Модульность.** Контроллеры, модели, представления. Всё по полочкам, по единому шаблону.
- **Мультипроектность.** Один код — десятки проектов. Изоляция данных через `project_id`.
- **Локализация.** Три уровня перевода: тексты в коде, крупные тексты в админке, переводные данные в БД. Автоматический перевод через очереди.
- **ORM без магии.** MySQL, PostgreSQL, MongoDB. Честные `JOIN` и понятные `WHERE`, без скрытого SQL.
- **Безопасность.** Динамическая подпись форм (меняется каждые 30 секунд), защита на уровне роутинга, brutus-логирование.
- **Без зависимостей.** Ни одного пакета через Composer. Вшита только jQuery 1.12.4.
- **Работает везде.** Apache/Nginx, PHP 7.4–8.x, MySQL 8.
- **Свой сервер очередей.** Демон + воркер через cron, разовые и возобновляемые задачи.
- **Собственный автолоадер.** Карта классов вместо PSR-4, учёт иерархии наследования.

## Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Stalker23051974/slot-h.git
cd slot-h

# 2. Импортировать схему БД
mysql -u root -p < Config/Schema/install.sql

# 3. Настроить подключение к БД
#    отредактировать Config/Domens/cli.ini

# 4. Создать конфиг проекта (имя = адрес сайта)
cp Config/Domens/cli.ini Config/Domens/127.0.0.1.ini

# 5. Создать папки для логов и дампов
mkdir -p Config/Logs/127.0.0.1
mkdir -p Config/Dump
sudo chown -R www-data:www-data Config/Logs Config/Dump

# 6. Сгенерировать автолоадер
php Application/Tools/createAutoloader.php
```

После этого настроить виртуальный хост на адрес из `project_landing` и открыть его в браузере.

Полная инструкция: [03. Быстрый старт](docs/ru/03-quick-start.md)

## Архитектура

Запрос приходит в `index.php` — единую точку входа. Далее:

1. **Router** инициализирует `Request`, определяет модуль/контроллер/экшен
2. Загружается **Bootstrap** модуля
3. **Preloader** проверяет авторизацию и права доступа
4. **Контроллер** обрабатывает запрос, вызывая модели явно (статически)
5. **Модель** работает с БД через `DbTables`
6. **View** рендерит шаблон из `Views/Project_<N>/`

**Ядро не знает о модулях. Контроллер не знает о модели.** Это позволяет подменять модели без изменения контроллеров и развивать систему без переписывания.

Подробнее: [06. Архитектура](docs/ru/06-architecture.md), [05. Принципы](docs/ru/05-principles.md)

## Демо-версия vs полная

Ядро **идентично** в обеих версиях. Отличается только набор модулей и их наполнение.

| Компонент | Демо | Полная |
|---|---|---|
| Модуль Base | Базовый | Расширенный (A/B, SEO) |
| Модуль Geo | Только языки/таймзоны | Страны, регионы, города (млн записей), валюты |
| Модуль Main (админка) | — | ✓ |
| Модуль Billing | — | ✓ |
| Интеграции (1С, AmoCRM, Bitrix) | — | ✓ |
| Очереди | Только дамп | Все типы |
| Безопасность | Базовая | +2FA, OAuth, fingerprint |
| Хелперы | Базовые | +пуш, PDF, SMS, карты, платежи |

Переход с демо на полную **не требует изменения кода**. Подробнее: [30. Сравнение](docs/ru/30-camparison.md).

## Разработка

```bash
# Пересоздать автолоадер (обязательно после любого нового класса)
php Application/Tools/createAutoloader.php

# Создать новый контроллер со всем окружением
php Application/Tools/createController.php

# Запустить очередь (через cron)
php Application/Tools/cli.php -stage=<проект> -module=Base -controller=Cli -action=demon
```

**Важно:** любой новый класс, переименование, перенос или удаление требуют перегенерации автолоадера. Иначе — `Class not found`.
